# 📝 Registration Form

A responsive and interactive **Registration Form** built using **HTML, CSS, and JavaScript**.

This project focuses on creating a clean user interface along with client-side form validation and interactive features.

## ✨ Features

* 📝 Full Name validation
* 📧 Email validation
* 📱 Phone number validation
* 🔐 Password validation
* 💪 Password strength indicator
* 👁️ Show/Hide password
* 🔄 Confirm password matching
* 📅 Date of Birth
* ⚧️ Gender selection
* 🌍 Country selection
* ☑️ Terms & Conditions checkbox
* ✅ Registration success popup
* 📱 Responsive design

## 🛠️ Technologies Used

* **HTML5** – Structure of the registration form
* **CSS3** – Styling, layout, animations, and responsive design
* **JavaScript** – Form validation and interactive functionality
